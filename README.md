# ⚖️ Almeida Advocacia — Website Institucional

Website moderno, responsivo e de alta conversão desenvolvido para o escritório **Almeida Advocacia**. O projeto apresenta os serviços do escritório, a trajetória do advogado responsável e oferece canais diretos de contato via WhatsApp e e-mail.

---

## 🚀 Tecnologias Utilizadas

* **React.js** (Vite)
* **Tailwind CSS** (Estilização)
* **Lucide React** (Ícones)

---

## 🎨 Funcionalidades

* **Design Responsivo:** Adaptado para celulares, tablets e desktops.
* **Agendamento Direto:** Botões de CTA direcionando para WhatsApp e formulário de contato.
* **Identidade Visual Profissional:** Cores e tipografia elegantes em tons de azul-marinho e dourado.

---

```bash
